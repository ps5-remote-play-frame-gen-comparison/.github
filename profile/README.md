## Getting Started Playbook

On PS5, go to **Settings → System → Remote Play** and switch on **Enable Remote Play**. Use a wired network for the first pass if available and set the PC monitor to 60 Hz under **Settings → System → Display → Advanced display**. Play the same 30-second sequence three times with each route unprocessed and note any recurring hitches before enabling frame generation.

On stable 30 fps content, try SmoovPlay at 60 fps or Lossless Scaling in Fixed x2 with the stream window focused. If SmoovPlay's Auto setting misreads known 30 fps content, use **Settings → Smoothness → Game frame rate** and select 30 fps. For a rough input-delay comparison, film the controller and screen together in slow motion, count frames from the visible press to the reaction, and compare the median of five presses per setting. Keep the unprocessed route if response degrades enough to affect play or motion still hitches repeatedly.

## Everyday Use

Start with the app that already connects reliably, and keep the PlayStation sign-in in the client that requests it. On a laptop, repeat the short test run after several minutes on AC power: a matching desktop RTX family name doesn't establish sustained mobile performance.

## Troubleshooting Common Issues

Which tool? Identify which tool you chose first; this comparison has no package of its own.  
Picture stutters? If the same hitch appears with generation off, investigate the stream before changing the interpolation model.  
Input feels delayed? Compare a physical press against the on-screen reaction at the same settings before attributing delay to interpolation.  
Setup incompatible? Verify the GPU and capture route separately, particularly on a laptop with switchable graphics.  
A tool updated? Consult the release notes for the component that changed, then rerun its unprocessed pass first.
